VSuite Lab is a cross-platform desktop application designed for managing journals, notes, tasks with sync support and powerful querying.

![Alt](https://repobeats.axiom.co/api/embed/e42bce804fd6fb09a90262b28a5711cf85cac5ac.svg "Repobeats analytics image")

## Features
- **Cross-Platform:** Works on Windows, Linux, and macOS.
- **Advanced filtering & sorting:**  Easily find all your items with complex filters, groups, and sorting rules
- **Sync support:** Connect to remote DAV services and keep your data in sync
- **Unified workspace:** Journals, notes, and tasks in a single application
- **Offline first:** Your data is always available locally

## Usage
- Add a DAV configuration to enable syncing
- Create journals, notes, or tasks
- Use the query builder to filter and organize your data
- Trigger sync manually or let it run automatically
